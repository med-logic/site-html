# МедЛогика

Чистая статическая версия сайта «МедЛогика» без React/Vinext runtime. Интерактивное контактное окно реализовано на обычном JavaScript. Шрифты Geist и Geist Mono подключаются через Google Fonts.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска сайт доступен по адресу <http://localhost:4173/>. Дополнительные страницы:

- <http://localhost:4173/medicine/>
- <http://localhost:4173/websites/>
