# МедЛогика

Статическая копия сайта «МедЛогика». Шрифты Geist и Geist Mono подключаются через Google Fonts, как в исходной верстке.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска сайт доступен по адресу <http://localhost:4173/>. Дополнительные страницы:

- <http://localhost:4173/medicine/>
- <http://localhost:4173/websites/>
